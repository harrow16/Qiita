# SPSS判別分析をPythonで再現する

SPSSの判別分析モデルを、SPSS環境なしに**Pythonで再現**するサンプルコードです。  
Fisherの線形判別関数（分類関数係数）を使い、SPSSと同等の分類結果を得ます。

詳しい解説は Qiita 記事を参照してください。

---

## ファイル構成

```
.
├── discriminant_fisher.py   # メインスクリプト
├── input.csv                # 入力データ（顧客1,000件）
└── output.csv               # 出力ファイル（実行後に生成）
```

---

## 必要環境

- Python 3.8 以上
- pandas

```bash
pip install pandas
```

## 使い方

### 1. CSVファイルを一括分類する

`input.csv` と同じフォルダで実行します。

```bash
python discriminant_fisher.py
```

`output.csv` に「予測グループ」列を付加したCSVが出力されます。

#### 実行例

```
--- 単一レコード分類の例 ---
判別分類(収入=80, 雇用=12, 世帯人数=3) → 'トータル サービス'

--- 入力データ（先頭3件）---
      収入  雇用  世帯人数
0   64.0   5     2
1  136.0   5     6
2  116.0  29     2

--- 分類結果（先頭3件）---
      収入  雇用  世帯人数        予測グループ
0   64.0   5     2  ベーシック サービス
1  136.0   5     6   トータル サービス
2  116.0  29     2     プラス サービス
```

### 2. 関数として呼び出す

```python
from discriminant_fisher import 判別分類

result = 判別分類(収入=80, 雇用=12, 世帯人数=3)
print(result)  # → 'トータル サービス'
```

### 3. 別フォルダから実行する場合

`classify_csv()` にフルパスを渡します。

```python
from discriminant_fisher import classify_csv

classify_csv(
    input_path=r'C:\data\input.csv',
    output_path=r'C:\data\output.csv'
)
```

## 仕組み

### Fisherの線形判別関数

SPSSの「分類関数係数」テーブルから読み取った係数を使い、グループごとにスコアを計算します。

```
Score_g = b1×収入 + b2×雇用 + b3×世帯人数 + 定数
```

**スコアが最大のグループ**に分類します（`idxmax`）。標準化（Zスコア変換）は不要です。

### 係数（本例）

| 変数 | ベーシック | E-サービス | プラス | トータル |
|---|---|---|---|---|
| 収入 | 0.002 | 0.003 | 0.002 | 0.005 |
| 雇用 | 0.101 | 0.118 | 0.160 | 0.104 |
| 世帯人数 | 1.184 | 1.276 | 1.256 | 1.410 |
| 定数 | −3.165 | −3.610 | −4.028 | −3.992 |

### SPSSモデルとの一致率

等共分散・等事前確率の条件下では、FisherスコアのidxmaxはSPSSの分類と**数学的に100%一致**します。

## 自分のデータに適用する方法

1. `FISHER_COEF` をSPSSの「分類関数係数」テーブルの値に書き換える
2. `required_cols` と各スコア計算の列名を自分のCSVの列名に合わせる
3. 実行する
